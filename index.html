WEB

食品容器卸売店のHPサンプル(架空)

飲食店向けの食品容器を扱う架空の会社を題材に制作したサンプルです。写真のスライドショー、1文字ずつ浮かび上がるキャッチコピー、スクロールで動くアニメーション、商品の詳細ページ、見積もりボタン、お問い合わせフォーム(入力チェック付き)、スマホ対応を備えています。写真はUnsplashのフリー素材です。Claude Codeで制作し、Vercelで公開しています。

公開サイトを見る →
TOOL

出荷リスト自動作成ツール(サンプル)

受注データのCSVを読み込むと、届け先ごとの出荷リストと、商品ごとのピッキングリストを自動で作ります。数量の異常・必須項目の抜け・郵便番号の形式・重複行も先に見つけます。結果はExcelで開けるCSVで保存できます。データはブラウザの中だけで処理し、サーバーには送りません。画面のデータはすべて架空です。HTML・CSS・JavaScriptのみで、APIキーや外部サービスは使っていません。物流現場の出荷準備を題材に、Claude Codeで制作しました。
